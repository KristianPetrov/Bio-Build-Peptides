# HANDOFF — Bio Build Peptides

_Last updated by Claude Opus 5.5 — 2026-10-01_

## Goal
Production-grade storefront for **Bio Build Peptides** (research-use-only peptides) on Next.js 16.3 + Neon
Postgres, deployed on Vercel (`set-free-digital-desciples/bio-build-peptides`, linked in `.vercel/`). Matches the
functionality of the owner's sites — Affordable Peptides (`~/Desktop/affordable-peptides`), East Coast Wellness
(`~/eastcoastwellness`), Pure Energy Peptides (`~/pure-energy-peptides`) — with a distinct Bio Build identity.

## Decisions confirmed with the owner
- **Catalog**: copy of the Affordable Peptides catalog (33 products, strengths, 1/5/10 prices). Copy rewritten as
  identity/classification text with no efficacy claims (AP's live site also swaps its claim copy for compliance
  text). AP certificates of analysis are **not** reused (they are AP lots); `coa_url` is editable per variant in admin.
- **Payments**: manual after order — Zelle, Venmo, Cash App, and a hosted pay link (Autobooks/Square). Each method
  appears only when its env var is set. No card processor.
- **Contact details / domain**: not provided yet → env-driven and hidden when empty.

## Design direction — "Gilded Helix" (Opus owns; preserve)
Reference: `.context/ref/image-for-the-style-of-bio-build.jpg` (also in main checkout `public/`).
- **Palette** (`app/globals.css` @theme): void `#050505`, onyx `#0C0B09`, umber `#16130E`; gold ramp `gold-50…800`;
  ivory `#F2EADB`, parchment, stone `#A99D88`, ash `#908675` (raised for WCAG AA). Gold is the only accent;
  ember/sage only for error/success.
- **Type**: Cinzel (wordmark, display caps), Cormorant Garamond italic (accent words), Jost (body/UI). Micro-labels
  `.eyebrow` tracked 0.32em like the logo tagline.
- **Motifs**: `.rule-label` hairline-flanked labels, `HelixGlyph`/`HelixRule` (components/brand.tsx), metallic
  `.text-gilt` / `.text-gilt-sheen`, `.btn-gold` / `.btn-ghost`, numbered section labels (01–05).
- **Product imagery**: one generated blank-label vial photo per container (`public/images/vial-3ml.png`,
  `vial-10ml.png`); `components/vial.tsx` overlays live typography in measured label boxes and auto-fits names.
  Dark images sit on dark surfaces with `.blend-lighten`.
- **Motion**: `[data-reveal]` fade-up via `RevealObserver`, staggered hero rise, wordmark sheen, drawer slide.
  All disabled under `prefers-reduced-motion`.

## Architecture
- `db/schema.ts` (users, products, product_variants, orders, order_items, referral_partners, referral_codes,
  contact_messages) · `db/index.ts` lazy Neon Pool · `db/seed.ts` idempotent catalog seed.
- `lib/catalog-data.ts` source catalog · `lib/pricing.ts` tier + loose-vial volume pricing (client & server)
- `lib/orders.ts` re-pricing, atomic stock reservation, order creation, restock on cancel
- `lib/payment-methods.ts` env-configured manual payments + instructions · `lib/auth.ts` jose JWT cookie + bcrypt
- `lib/order-access.ts` signed cookie after a successful `/track` lookup · `lib/email.ts` Resend (no-op if unset)
- Routes: `/`, `/shop`, `/shop/[slug]`, `/checkout`, `/order/[reference]`, `/track`, `/account{,/login,/register}`,
  `/admin{,/orders/[id],/products,/referrals,/messages}`, `/science`, `/about`, `/faq`, `/contact`, `/terms`,
  `/privacy`, `/research-use`, sitemap/robots/manifest/OG.
